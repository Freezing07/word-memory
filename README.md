# 单词记忆工具（列表模式）

一个纯前端的单文件英语单词记忆工具。核心是**标记制**：记住就标记，没记住不动，没记住的词会一直回来。

- 无后端、无依赖、无构建
- 单词内容与学习进度全部存在浏览器 `localStorage`
- 发音用浏览器 Web Speech API

**相关文档**：[`词库生成指南.md`](词库生成指南.md) —— 怎么写词库、给 LLM 的提示词模板；`sample-words.json` 是 30 词的现成例子。（阶段 5 接入）

## 如何使用

双击 `index.html` 用浏览器打开即可（Chrome / Edge / Firefox 均可）。

### 日常操作

| 操作 | 说明 |
| --- | --- |
| **记住了** | 该词被**收到下方"今日已记住"区**，上方不再显示，以后也不再出现 |
| **没记住** | 留在**上方"未记住"区**，`failCount + 1`，明天继续出现 |
| 什么都不做 | 留在上方；**明天不再出现**（"过时不候"，见下） |
| **导入词库** | 右上角按钮，选择 JSON 文件，可选「合并」或「替换」 |
| **键盘模式** | 右上角按钮进入拼写练习，`Esc` 或按钮返回列表 |
| **设置** | 每日词数、显示音标、显示例句、默认进入键盘模式、重置进度 |
| **点击单词本身** | 展开/收起 `scene`（场景）和 `example`（例句） |
| **导出进度** | 底部按钮，下载一个 JSON 文件 |
| **打卡** | 顶栏按钮，今日任务全部处理完后可打卡，含连续天数与月历 |

标记是可反复改判的：点错了直接点另一个按钮即可覆盖。

## 主界面：上下两个区域

```
┌─ 未记住 ─────────────────────── 12 ─┐
│  认为记住了就点右下角「记住了」        │
│  abandon   /əˈbændən/   v.放弃       │
│    🔊  [记住了] [没记住]              │   ← 未处理的词
│  absorb    /əbˈzɔːrb/    v.吸收       │
│    🔊  [记住了] [没记住] 没记住 ×2     │   ← 标了"没记住"的也留在这里
└──────────────────────────────────────┘
┌─ ▸ 今日已记住 ────────────────── 3 ─┐   ← 默认折叠，点标题展开
└──────────────────────────────────────┘
```

- **上半部分「未记住」**：今日任务的全部词一开始都在这里。点「没记住」的词**仍留在这一区**（带 `没记住 ×N` 标记），明天继续出现。
- **下半部分「今日已记住」**：只装**今天**点过「记住了」的词，**默认折叠**，点标题展开。
- 展开后每一行仍带一个「**没记住（撤回）**」按钮——点它这个词会**回到上方**，并 `failCount + 1`。

## 自测模式（闭卷）

顶栏的「**自测模式**」按钮打开后，**上半部分「未记住」区**会变成闭卷：
| 元素 | 自测模式下 |
| --- | --- |
| 中文释义 | **隐藏**，位置显示"点一下看释义" |
| 单词本身 / 音标 / 🔊 发音 | 保留 |
| 「记住了」「没记住」 | 保留 |
| 状态角标 | 保留 |
| 场景 / 例句 | 取不到（**不可展开**） |

- **点一下单词就能对答案**：临时显示这条的释义，再点一下收起。所以想不起来时能核对，不会出现"永远看不到答案"的情况
- 下方「今日已记住」区**不受影响**（那里的词你已经判断过了，展开照常能看释义和例句）
- 按钮打开时会**高亮**并变成「退出自测」，一眼能看出模式开着
- 开关状态**会存进设置**，刷新后仍然生效；但**对答案的记录不会保留**，刷新后重新盖住

### 自测模式下键盘模式会反过来

两个页面正好互补——列表页是"看英文想中文"，键盘模式是"**看中文拼英文**"：

| | 列表页（未记住区） | 键盘模式 |
| --- | --- | --- |
| 自测模式**关** | 英文 + 中文 + 音标 + 发音 | 英文 + 音标 + 中文 + 发音 |
| 自测模式**开** | 英文 + 音标 + 发音（**中文藏起来**） | **只有中文和词性**（英文、音标、发音全藏起来） |

自测模式下进键盘模式，画面只剩一句放大的中文释义和输入框，你要**凭记忆把英文敲出来**。敲错仍然会变红并锁住、必须退格——这条机制没变。退出自测模式后键盘模式立刻恢复原样。

> **两种页面里都能切换自测模式**：顶栏的按钮在列表页和键盘模式里都有效，点了立刻生效（键盘模式里切换不会丢已经敲了一半的字母）。

## 打卡

顶栏的「打卡」按钮打开打卡页。**规则：今日任务里的词全部标记完（记住 + 没记住都算）才能打卡。**

> 注意：标记只算**列表模式**里点的按钮。键盘模式是纯拼写练习，不写进度，所以**不会帮你满足打卡条件**。

- **手动打卡** —— 任务没做完时按钮是灰的，并提示"还剩 N 个词"
- **今日状态卡** —— 显示 `今日任务 12/12`、进度条，以及打卡按钮 / 已打卡时间
- **连续打卡 / 累计打卡 / 本月打卡** 三个统计
- **月历** —— 用颜色区分三种日子：
  - 🟩 **已打卡**（绿色实心）
  - 🟦 **学习过但没打卡**（浅蓝）—— 由单词的 `lastReview` 反推出来
  - ⬜ 没有学习记录；今天带蓝色描边；未来日期变淡
  - 可以往前翻月份，但不能翻到未来
- 打错了可以**取消今日打卡**（只能取消当天）

### 打卡成功的庆祝动画

点下「今天打卡」后会弹出一层**毛玻璃虚化的庆祝动画**：

- 背景整页虚化（`backdrop-filter: blur`）
- 中间弹出一张卡片：一个**随机**的大 emoji（😎 🎉 🥳 💪 🚀 🌟 🤩 🔥 … 共 15 个）+ 随机文案（"今日任务已完成！"/"今天的词全过啦！"）+ 完成度与连续天数
- 四周飘起 **12~17 个随机 emoji**，位置、大小、延迟、时长都随机
- **3.2 秒自动收起**，也可以点任意位置或按 `Esc` 立即关掉（`Esc` 会优先关动画，不会顺手退出打卡页）

想单独看效果：控制台执行 `wordMemory.checkin.celebrate()`

### 连续天数怎么算

从今天往前数连续打卡的天数。**今天还没打卡不算断**（从昨天开始数），所以白天没打卡不会立刻把连续天数清零——过了今天才断。

### 打卡数据

存在 `state.checkins`：

```json
"checkins": {
  "2026-09-10": { "at": "2026-09-10T05:07:21.960Z", "done": 12, "total": 12 }
}
```

- 键是本地日期 `YYYY-MM-DD`，值是打卡时刻和当天完成度
- 跟着「导出进度」一起备份，导入时一并恢复
- 导入文件里如果是**不存在的日期**（比如 `2026-13-99`）会被丢掉，不污染统计
- 「重置进度 → 清空学习进度」会连打卡记录一起清掉

## 设置面板

| 项目 | 说明 |
| --- | --- |
| **每日词数** | 默认 50，范围 1~1000。改完**立即重排今日任务**；今天已经标记过的词不会被挤掉 |
| **主题** | 跟随系统 / 浅色 / 深色，也可点顶栏的 🌙 / ☀️ 圆按钮一键切换 |
| **界面字号** | 小 / 标准 / 大 / 特大，整体缩放界面文字 |
| **英文字体** | 衬线（字典感）/ 无衬线（现代）/ 等宽（打字感），作用于单词词头 |
| **自测模式** | 隐藏列表上方区域的中文释义，点单词可临时对答案（顶栏也有按钮） |
| **显示音标** | 关掉后列表和键盘模式都不显示音标 |
| **显示例句** | 关掉后展开单词时只显示场景，不显示例句 |
| **直接进入键盘模式** | 打开页面就跳到拼写练习（下次打开生效） |
| **重置进度…** | 见下 |

设置改完即生效、即存盘，关掉面板不会丢。

### 深色模式

- **跟随系统**（默认）：系统切深浅色，页面跟着变
- 顶栏那个 🌙 / ☀️ 圆按钮是快捷开关，点一下会在浅色/深色之间切，并把设置**固定成显式值**（不再跟随系统）
- 深色主题的所有颜色都在 `index.html` 的 `:root[data-theme="dark"]` 里，变量块之外没有任何硬编码颜色（有测试守着这条）
- 页面加载前会先跑一小段脚本定下主题，所以深色下打开**不会先闪一下白屏**
- 表单控件（勾选框、下拉框、数字框）通过 `color-scheme` 跟随主题

### 字体与字号

- **界面字号**通过 `html{ font-size:calc(16px * var(--fs-scale)) }` 实现，所有文字尺寸都用 `rem` 写，所以是一起缩放的
- **英文字体**改的是 `--font-head` 变量，只作用于单词词头（列表里的单词、键盘模式的大字、例句英文），中文界面保持不变

视觉相关的取值全部收在 `index.html` 顶部的两个 `:root` 变量块里，想微调改那里就行。


### 重置进度（二次确认）

点「重置进度…」会弹出确认框，里面有两条路：

- **清空学习进度** —— 词库保留，所有词变回 `new`，`known` 和 `failCount` 全部归零
- **清空全部数据** —— 词库和进度一起清掉，回到内置的 5 个测试词

## 导出 / 导入进度（换设备）

「导出进度」会下载 `word-memory-progress-YYYY-MM-DD.json`，内容与 `localStorage` 里的结构**完全一致**（词条、进度、设置都在里面）。

换到另一台设备时：打开页面 → **导入词库** → 选这个文件 → 选 **替换** → 学习进度和设置一起恢复。

> 「替换」才是"恢复备份"；「合并」是往现有词库里加词（保留现有进度，不覆盖）。

## 键盘拼写模式

进入后屏幕显示单词、音标、释义，直接敲键盘逐字母输入。

- **敲对**：字母变绿，光标前进
- **敲错**：该字母变红 + 输入框整体变红并抖动，**此后输入被锁住**
- 必须按 `Backspace` 把红字母删掉才能继续 —— 这是刻意的（避免形成错误肌肉记忆）
- 整词敲完 → 停 300ms 显示判定结果 → 自动切下一个词
- 底部实时显示 **正确率**（敲对的按键 / 总按键）和 **WPM**（敲对字符数 ÷ 5 ÷ 分钟）
- 每个词都有 **🔊 听发音** 按钮，`Esc` 返回列表

### 判定规则：纯拼写练习，不影响进度

**键盘模式和记忆进度完全脱钩** —— 练完不写任何东西。

| 情况 | 结果 |
| --- | --- |
| 全程无错敲完 | 面板显示「✓ 记住了」（**只是本轮表现，不会把这个词标记为已掌握**） |
| 中途敲错过 | 面板显示「✗ 中途敲错过」（**不会记为没记住，也不加 failCount**） |

所以：

- 键盘模式里怎么练都**不影响**今日进度、复习池、已掌握数量、打卡门槛
- 不会写 `status` / `failCount` / `lastReview`，练完连 `localStorage` 都不会被写一次
- 想把词真正标记为记住 / 没记住，请回**列表模式**点按钮

> 面板底部有一行小字说明这件事，免得你以为练过就算记过了。

### 练习范围

本轮队列 = **今日任务列表里的全部词，一个不落**（不排除已掌握的词，也不跳过今天已标记过的词）。每次进入键盘模式都**从今日第 1 个词开始**，练完一轮显示完成页，可以重开一轮。

> 完成页上的「记住 X 个 / 没记住 Y 个」只是本轮表现的小结（全对几个、中途错过几个），不代表任何进度变化。

### 手机 / 平板（Android、iOS）

键盘模式用的是屏幕外的**真实 `<input>`**（`.kbd-input`，透明、不挡点击），字符统一由 `input` 事件接收，所以手机软键盘能正常用：

- 点「键盘模式」会自动聚焦输入框并**弹出软键盘**（必须在点击手势里触发，否则浏览器会拦）
- 软键盘收起来了？**点一下面板任意位置**就能再次唤起
- 输入框永远保持焦点，切到下一个词时键盘不会跟着收起来
- 点「返回列表」会主动 `blur()`，避免软键盘一直盖在列表上
- 桌面端如果焦点跑到别处，`keydown` 会自动兜底，物理键盘照样能敲（两条路不会重复计字符）

**输入时页面不会上下跳动**（手机端专门处理过，这四条缺一不可）：

1. 透明输入框贴在**屏幕顶部**——放底部会被软键盘盖住，浏览器为了"露出"光标就会滚页面
2. **打字过程中绝不调用 `setSelectionRange()`**——这个 API 会让手机浏览器把光标滚进可视区，是"每敲一个字母跳一下"的主因；只在聚焦时调一次
3. 进入键盘模式先把页面滚到顶部再聚焦，软键盘弹出时没有需要"露出"的东西
4. 聚焦时万一被浏览器滚走，会记下位置并还原

> 输入框设了 `inputmode="latin"`，一般会切到英文键盘。如果你的输入法仍处于**中文拼音**状态，个别输入法可能在提交候选词时行为异常，切成英文键盘即可。



## 每日任务是怎么排出来的

每天打开程序时，今日名单按下面的顺序组成：

1. **今天已经标记过的词** —— 留在名单里（记成"已记住"的要显示在下方区域）
2. **复习池** —— 所有 `status === 'unsure'` 的词，**全部纳入**，按 `failCount` 降序（错得多的排最前）
3. **新词** —— 只从**还没派发过**的新词里按词库顺序取，补足到每日上限（默认 50）

> 复习池大于每日上限时，复习池整池保留、不再补新词，所以当天任务条数可能超过上限。

### ⚠️ 「过时不候」规则

一个词只要**被派发进某天的任务**，就会记下派发日期（`servedOn`）。之后：

| 那天你对它做了什么 | 以后会怎样 |
| --- | --- |
| 点了「记住了」 | 成为已掌握，永不再出现 |
| 点了「没记住」 | 进入复习池，**明天继续出现在上方** |
| **什么都没做** | **不再自动派发**（词还在词库里，只是不再发给你） |

这就是"每天发一批、过时不候"：你不用把今天的词处理完，明天照样会往后推进到新的词，**不会卡在同一批上反复出现**。

> 副作用要知道：如果一个词被你跳过（没点任何按钮），它以后不会自己回来了。想重新学它，可以「重置进度」（会清掉所有进度）或重新导入词库。

**同一天内名单是稳定的**：名单连同日期写入 `localStorage`，刷新页面不会涌入新词；而且因为派发日期记的是"今天"，同一天内重建任务（比如改每日词数）**不会让名单缩水**。

> 顶栏「今日已记住 A/B」：A = 今天点过「记住了」的词数，B = 今日任务总数。

## 数据存在哪

浏览器 `localStorage`，键名 `wordMemory.v1`，结构如下：

```json
{
  "words": [
    {
      "word": "abandon",
      "phonetic": "/əˈbændən/",
      "meaning": "v. 放弃，抛弃；离开",
      "scene": "场景化描述…",
      "example": "The crew had to abandon the sinking ship.",
      "exampleCn": "船员们不得不弃船逃生。",
      "status": "new",
      "failCount": 0,
      "lastReview": null,
      "servedOn": "2026-09-10"
    }
  ],
  "settings": { "dailyLimit": 50, "showPhonetic": true, "showExample": true, "keyboardMode": false },
  "todayTask": { "date": "2026-09-10", "words": ["abandon", "ability"] }
}
```

- `status`：`new`（新词）/ `unsure`（没记住）/ `known`（已掌握）
- `failCount`：累计“没记住”次数。同一个词**同一天内最多只 +1**，避免手滑连点把计数刷高；跨天再忘会继续 +1
- `lastReview`：最后一次标记的日期，格式 `YYYY-MM-DD`
- `todayTask`：今日任务名单，按已确认的设计当天固定

### 想清空重来

浏览器控制台（F12）执行：

```js
wordMemory.reset()      // 清空全部数据，回到内置 5 个测试词
wordMemory.state        // 查看当前完整数据
```

## 词库 JSON 格式

`sample-words.json` 是一份 30 词的可用示例（其中 5 个与内置测试词同名，用来演示「合并」的更新效果）。

```json
[
  {
    "word": "abandon",
    "phonetic": "/əˈbændən/",
    "meaning": "v. 放弃，抛弃；离开",
    "scene": "想象你站在一艘即将沉没的船上…",
    "example": "The crew had to abandon the sinking ship.",
    "exampleCn": "船员们不得不弃船逃生。"
  }
]
```

- `word`、`meaning` 必填；缺任一项的条目会被跳过，并在导入结果里报数
- `phonetic`、`scene`、`example`、`exampleCn` 可选
- 也支持直接导入本工具导出的进度文件（`{"words": [...], "settings": {...}}`）

> 详细的字段写法、`scene` 的写作技巧、常见错误、以及**可直接复制给 LLM 的提示词模板**，见 [`词库生成指南.md`](词库生成指南.md)。

### 导入的两种模式

| 模式 | 行为 |
| --- | --- |
| **合并**（推荐） | 按 `word` 去重（忽略大小写）。新词追加到词库末尾；已有的词只更新释义/音标/场景/例句等文本，**学习进度完整保留**。文件内的重复条目只取第一条 |
| **替换** | 清空现有词库和**全部学习进度**，只保留该文件的内容 |

导入结束后，今日任务会立即重新生成，所以新导入的词当天就能出现在列表里。

## 界面说明

- **顶栏**：日期、今日进度，下沿一条进度条随标记实时增长
- **列表行**：`▸ 单词 /音标/ [角标]` + 释义，右侧 `🔊 记住了 没记住`
  - 点**单词区域**展开场景与例句；点 **🔊** 只发音、不会误触标记，也不展开
  - 已掌握 = 绿色左边框 + 灰化划线；没记住 = 橙色左边框 + `没记住 ×N` 角标
- **键盘模式**：大号词头 + 音标 + 释义，逐字母输入框，底部正确率 / WPM / 进度

视觉相关的取值（配色、圆角、阴影、英文字体）全部收在 `index.html` 顶部的 `:root` 变量里，想换风格改那一段就行。英文词头用的是衬线体（字典观感），不喜欢把 `--serif` 改成 `inherit` 即可。

另外支持窄屏（≤640px 自动换行）和系统「减少动态效果」设置。


## 各阶段已确认的设计决定

1. **今日进度分子/分母**：分子 = 今天标记过的词数（记住 + 没记住都算），分母 = 今日任务总数。
2. **当天标记后的行为**：点“没记住”的词当天**留在列表里**、标记为未完成，可以反复点，明天照样回来。
3. **键盘模式判定**：中途敲错过（哪怕最后敲对了）就算 `unsure` 且 `failCount + 1`。
4. **今日任务列表稳定**：任务名单当天固定并写入 `localStorage`。
5. **不做**：登录、云同步、复杂 SRS 间隔算法、多语言、移动端专门适配。

### 一处对需求文档的有意偏离

文档 5.2 建议用 `new Date().toISOString().slice(0, 10)` 取“今天”。**这个写法在 UTC+8 有时区 bug**：`toISOString()` 返回的是 UTC 日期，在东八区凌晨 0:00~8:00 之间会算成“昨天”，导致凌晨学习的进度被记到前一天。

本实现改为按**本地日期**格式化，输出格式仍是 `YYYY-MM-DD`，与文档一致：

```js
function today() {
  const d = new Date();
  const p = n => String(n).padStart(2, '0');
  return d.getFullYear() + '-' + p(d.getMonth() + 1) + '-' + p(d.getDate());
}
```
